# Customer Churn Prediction

A machine learning project that predicts customer churn and provides an interactive Streamlit dashboard for analyzing customer churn risk.

## 🚀 Features

- Customer churn prediction
- Churn risk assessment
- Interactive Streamlit dashboard
- Customer-level predictions
- Bulk CSV prediction
- Exploratory data analysis
- Model performance comparison
- Confusion matrix and ROC curve
- Feature importance analysis
- PDF prediction report

## 🤖 Machine Learning Models

The project compares:

- Logistic Regression
- Random Forest
- XGBoost

SMOTE is used to handle class imbalance, and feature scaling is applied where required.

## 🛠️ Technologies Used

## 🎯 Objective

The objective of this project is to use machine learning to identify customers who are likely to churn and provide an interactive dashboard for understanding churn patterns and customer risk.
